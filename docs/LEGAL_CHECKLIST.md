# 법적·운영 체크리스트

법률 자문이 아니다. 항목별로 담당 기관 안내나 전문가 확인이 필요하다.

## 출시 전
- [ ] **개인정보처리방침** 게시 (`/privacy` 초안에 상호·대표자·연락처·위탁업체명 채우기). 이메일 주소 수집 시 필수.
- [ ] **수신동의**: 가입 폼 체크박스(구현됨) + 모든 메일에 수신거부 링크(구현됨). 정보통신망법상 광고성 정보 전송 규정 적용 가능성 — 서비스 알림이라도 프로 요금제 유도 문구가 들어가면 광고성 정보로 볼 여지가 있으므로 동의 받는 구조를 유지.
- [ ] **공공데이터 이용조건**: 기업마당·공공데이터포털 각 API 의 이용약관(출처 표시, 상업적 이용 가능 여부, 호출 제한) 확인. 메일·페이지 하단에 출처 표시(구현됨).
- [ ] **면책 고지**: 자격 판정은 참고용 — 메일과 페이지에 표시(구현됨).

## 유료 전환 시
- [ ] 사업자등록 (부업이면 회사 취업규칙의 겸업 조항 먼저 확인)
- [ ] 통신판매업 신고 (온라인 유료 구독 판매)
- [ ] PG 가입 (사업자등록번호 필요), 이용약관·환불 규정 작성
- [ ] 부가가치세 신고 (간이/일반 여부 확인)

## 데이터
- [ ] 수신거부·삭제 요청 시 삭제 절차 (현재: `active=False` 처리. 삭제 요청은 관리자가 DB 에서 삭제 — 추후 셀프 삭제 버튼)
- [ ] LLM 에 보내는 데이터: 사업 프로필(이메일 제외)과 공공 공고문. 개인정보 최소화 유지.
