# 지원사업 레이더 — 기획서 (v0.1, 2026-09-12)

> 표기 규칙: **[사실]** 확인된 것 / **[가설]** 검증 전 판단 / **[확인 필요]** 운영 전 직접 확인할 것.

## 1. 한 줄 정의
소상공인·1인 사업자가 실제로 신청 자격이 되는 정부 지원사업 공고만 골라, 자격 근거·마감일과 함께 이메일로 보내주는 구독 서비스.

## 2. 왜 이걸 만드나
- **[사실]** 기업마당·K-Startup 등에는 매일 다수의 지원사업 공고가 올라오고, 공고문마다 지역·업력·직원 수·업종 제한이 다르다.
- **[가설]** 사장님은 공고 원문을 읽고 자격을 판단할 시간이 없다. 기존 알림(키워드 매칭)은 '해당되지 않는 공고'까지 보내서 결국 안 읽게 된다.
- **[가설]** 차별점은 수집이 아니라 **판정**이다: 공고 원문의 자격 요건을 프로필과 대조해 "되는 것만, 왜 되는지"를 보낸다. 이건 LLM이 생기기 전엔 사람이 해야 했던 일이다.

## 3. 타겟
1차: 직원 0~4명, 업력 0~5년의 생활서비스업·온라인판매 소상공인 (카페, 음식점, 미용, 쇼핑몰, 1인 개발/디자인).
- 이유 **[가설]**: 지원사업이 가장 많이 겨냥하는 집단이면서 정보 접근이 가장 약하다. 컨설턴트를 쓸 규모는 아니고, 월 1만원 구독은 부담 없다.

## 4. 제품 범위 (이번 버전에 들어간 것)
| 영역 | 내용 | 상태 |
|---|---|---|
| 수집 | 기업마당 오픈API, K-Startup(공공데이터포털) 어댑터, 로컬 픽스처 | 코드 완료, **[확인 필요]** 실제 API 필드명 |
| 매칭 | 규칙 필터(지역·마감·단계) → LLM 채점(적합도, 자격 yes/no/unclear, 한 줄 요약, 근거) | 완료, 채점 캐시로 비용 상한 |
| 발송 | 무료: 주 1회 상위 3건 / 프로: 매일 전부 + 근거. 더블 옵트인, 수신거부 링크 | 완료 (console/Resend/SMTP) |
| 웹 | 랜딩 + 가입 폼, 알림 설정, 수신거부, 개인정보처리방침 초안, 관리자 현황 | 완료 |
| 결제 | 결제 링크 URL만 연결하는 구조 (프로 전환은 수동/후속) | **미완** — 사업자등록 후 |

## 5. 요금 **[가설]**
- 무료: 주 1회, 상위 3건, 한 줄 요약 + 마감일. → 가입 장벽 0, 프로 전환 유도(숨긴 건수 표시).
- 프로: 월 9,900원. 매일, 전부, 자격 근거, 마감 7일 전 강조.
- 검증 방법: 무료 가입 100명 확보 → 결제 링크 붙인 뒤 전환율 측정. 전환율 3% 미만이면 가격/가치 제안 재검토.
- 대안: 연 79,000원 선결제, 또는 '건당 신청서 초안 작성' 유료 부가 서비스.

## 6. 경쟁 **[확인 필요]** (기억 기준, 운영 전 직접 검색·비교)
- 기업마당 자체 맞춤 알림(무료, 키워드 기반) — 가장 큰 경쟁자이자 가장 큰 차별화 근거.
- 웰로(Welllo), 정책브리핑, 각종 소상공인 정보 앱 — 대부분 무료 B2C + B2B 수익.
- 입찰 알림 서비스(비드톡톡 등)는 나라장터 영역이라 타겟이 다름.
→ 이들이 '자격 판정 + 근거'를 이미 제공한다면 이 제품의 차별점은 약해진다. **가장 먼저 확인할 것.**

## 7. 단위 경제 **[가설]**
- LLM 비용: 사용자 1인당 하루 최대 25건 채점(설정값). Haiku 계열, 입력 ~1.5k 토큰/건 기준 하루 수십 원 수준으로 추정. 무료 사용자가 많아지면 채점 상한을 낮추거나 주 1회만 채점.
- 이메일: Resend 무료 구간(월 수천 통)으로 초기 충분 **[확인 필요]**.
- 호스팅: Fly.io/Railway 소형 인스턴스 + SQLite → 월 수천~1만 원대.
- 손익분기: 프로 10명이면 인프라 비용은 넘는다. 그 이상은 전부 시간 대비 수익.

## 8. 리스크
| 리스크 | 대응 |
|---|---|
| 판정 오류로 사장님이 헛수고 | 모든 화면·메일에 '참고용, 원문 확인' 고지. unclear 판정을 숨기지 말고 '확인 필요'로 보여준다 |
| API 필드 변경/중단 | 어댑터가 매핑 딕셔너리만 보므로 수정 비용 낮음. 한 소스 실패해도 배치는 계속 |
| 스팸 분류 | 더블 옵트인, 수신거부 링크, 발신 도메인 SPF/DKIM 설정(DEPLOY.md) |
| 기업마당이 같은 기능을 무료로 제공 | 그 경우 '신청서 초안 작성' 같은 다음 단계로 이동 |
| 개인정보 | 수집 항목 최소화, 처리방침 게시, 삭제 요청 처리 |

## 9. 출시 순서
1. 오픈API 키 발급 → 실제 응답으로 어댑터 필드 검증 → 1주일 수집 데이터 확인
2. SCORER=anthropic 으로 전환, 본인 프로필로 채점 결과 20건 눈으로 검수 (프롬프트 튜닝)
3. Resend + 도메인 설정, 배포, 매일 07:00 KST 크론
4. 무료 가입자 모으기: 소상공인 커뮤니티(아프니까 사장이다 등), 당근 동네생활, 지역 상인회 — 가입 링크 + 샘플 메일 캡처
5. 무료 100명 → 결제 붙이기 → 전환율 측정
